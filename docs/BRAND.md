## 3. 规格与安全区

- 自适应图标画布 **108 dp**，系统只显示中心 **72 dp**（半径 36 dp），外面 18 dp 是给视差动画留的出血，任何遮罩都可能切掉。因此徽章直径取 **72/108**：徽章外圈正好落在可见边缘上，`DSH` / `MOBILE` 文字外缘半径约 **29.9 dp**，距遮罩还有约 6 dp 余量。
- 对照测试过 86/108（79.6%）：文字会贴到遮罩边缘、`MOBILE` 在圆形遮罩下被切；66/108 则出现一圈空白背景。72/108 是这张“环形文字”构图唯一不丢字的比例，已在圆形与方圆遮罩下逐尺寸验证。
- 旧启动器（API 26 以前）与文档/商店图不被系统遮罩，用 **88%** 的徽章比例，避免四周出现大块留白。
- 通知小图标必须是**单色 alpha** 图形：Android 会把小图标当作遮罩上色。原先复用的彩色 `appicon` 会被渲染成白色块，现已改为 `Resource.Drawable.ic_notification`（见 `HarnessForegroundService` 与 `RelayServices`）。
- 启动页：Android 12+ 冷启动默认使用应用图标，因此换了 `appicon` 即同时生效；未单独配置 `windowSplashScreenAnimatedIcon`。
- 商店图不要带圆角、阴影或透明通道——圆角由商店/系统遮罩决定。

## 4. 再生成

改母版后重跑，不要手工改各密度 PNG：

```bash
python tooling/brand/build-icons.py
```

脚本读取 `docs/brand/dsh-mobile-art-1024.png`（圆心 `(511.5, 511.5)`、半径 `504`）：自适应图标按 `72/108`，旧启动器与文档/商店图按 `88%`，一次生成全部密度与 `docs/brand/` 图。

## 5. 若要用图像模型重出一版（可选）

当前资产由现有插画**本地修图派生**（本次没有可用的图像生成工具）。若之后要重出一张更“图标化”的原图，按以下约束写 prompt，产出替换 `dsh-mobile-art-1024.png` 后重跑脚本即可：

> 同一角色（蓝发女仆、闭眼大笑、身旁蓝色鲸鱼玩偶、白米饭碗、手机）的方形应用图标插画：**不要出现任何商标或写实品牌标志**（尤其不要鲸鱼 logo、喷水标志）；背景为浅蓝 `#D8E8F7` 平铺到画布四边；主体居中，四周留约 15% 安全边距；扁平赛璐璐上色、干净描边、无明显投影；输出 2048×2048 PNG。
>
> 需要环形 `DSH` / `MOBILE` 字样时，单独排字（矢量或文字图层），不要烘焙进画面，以便在图标里按 72 dp 安全区定位。
