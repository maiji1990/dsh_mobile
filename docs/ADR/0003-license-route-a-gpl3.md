# ADR-0003：发行许可采用路线 A（GPL-3.0）

- 状态：已接受（2026-11-09），**正式发布前需许可证审核**
- 来源：方案 12.3 节

## 决策

- 本仓库整体以 **GPL-3.0** 发布（根目录 `LICENSE` 为 GPL-3.0 原文），因为 App 链接并分发 DSHBox GPL-3.0 源码派生的 AAR。
- 独立组件（如 Apache-2.0 的 `interlock-relay-core`、Termux 终端 Apache-2.0 部分）保留其原许可与署名。
- 品牌：App 名称 “DSH Mobile”、图标、Splash 全部为新资产；不使用 DSHBox 名称/图标/品牌图形，不自称 “DeepSeek 官方客户端”。
- 发布 APK 时必须同时提供对应版本源码（含子模块固定 SHA）。

## 后果

- 闭源商业路线（路线 B）不可在此代码基础上进行；如需要，必须洁净室重写并经法律评估。
- 本 ADR 是工程规划，不构成法律意见。
