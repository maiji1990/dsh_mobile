# ADR-0026：文件 Provider（按真实权限的能力）、回收站、编辑冲突与压缩包的安全约束

- 状态：已接受（2026-11-16，vNext PR-09 第一段）；**无真机证据**，真机验收见下「验收」
- 关联：TASK-007（`WorkspaceFileSystem`：相对路径、不跟随链接、`.dsh` 受保护）；[ADR-0021](0021-product-ui-material3.md)（界面）；
  AGENTS.md 规则 5（不伪造成功）、9（真机证据）、11（安全不削弱）、12（Material 3 与截图级验收）

## 背景

文件页只能浏览、预览文本、SAF 导入导出。方案 PR-09 要求：Provider 抽象（工作区、SAF、之后 SFTP），各能力**按 Provider 的真实权限暴露**；
批量复制 / 移动 / 删除；文本编辑时记录原哈希 / mtime、外部变更提示冲突、不静默覆盖；zip / tar 先在 staging 解包、不信任包内路径；
`.dsh` 与凭据维持保护；创建→编辑→复制→导出→撤销 / 冲突提示的完整闭环。

## 决策

1. **`IFileProvider` + `FileCapabilities`**（Core）：Provider 给出整体能力，`CapabilitiesOf(entry)` 给出单个条目能做什么；界面只显示这些动作。
   能力之外的调用是 `NOT_SUPPORTED`，从不返回假成功。批量操作逐项报告失败（`TransferResult` / `DeleteReceipt`），其余照常完成。
2. **工作区 Provider 沿用并收紧 `WorkspaceFileSystem` 规则**：`.dsh` 双向不可触——不读、不改、不删、不改名（包括 `.dsh` 本身），
   也不能被写入 / 移入 / 复制入 / 解压入；根目录不能删除或改名。符号链接是独立条目：可改名 / 移动 / 删除（只动链接本身，测试验证目标不变），
   不读取，复制时跳过并计数；递归删除遇到链接只解除链接、不下行。
3. **写入**：同目录临时文件 → fsync → rename 替换，保留目标的 Unix 权限位（编辑后的脚本仍可执行）。保存带上打开时的 `FileVersion`
   （长度 + mtime + SHA-256）；替换前、替换瞬间前各比较一次，不符即 `CONFLICT`，文件保持对方的版本。冲突时由用户选择：继续编辑 /
   放弃并重载 / 用我的版本覆盖（覆盖也是针对**当前**版本的原子写，若又变了再提示）。
4. **文本**：`TextDocument` 按 BOM 识别 UTF-8 / UTF-16，往返逐字节一致，保存时恢复文件原本的主行尾；不是 UTF-8 的（如 GBK）只读打开、
   绝不重新编码；含 NUL 视为二进制、不打开；1 MiB 上限。JSON 校验只给警告，不阻止保存。
5. **回收站**：删除 = rename 进 `files/dshmobile-files-trash/<批次>/`（在工作区之外——DSH 看不到、也不会索引；与工作区同一文件系统，
   删除是原子 rename），每移一项就更新清单，进程中途被杀仍可恢复。撤销把条目放回原处（原名被占加后缀、原目录已不在则回到根），
   7 天后清理。没有回收站目录时删除为永久，能力中没有 `Trash`，确认框明说「无法撤销」。
6. **压缩包是不可信输入**：解到目标目录旁新建的 staging 目录，全部条目通过才 rename 成最终目录（重名加后缀，从不合并进已有目录），
   任何失败删除 staging、不留痕。条目名先经 `NormalizeRelative`（绝对路径、盘符、`..`、NUL 拒绝），再逐段要求是干净的文件名（第二道防线：
   变异检查显示去掉规范化后仍由逐段校验挡住 `..`）。不创建符号链接 / 硬链接 / 设备 / FIFO（列在「跳过」里）；重名（忽略大小写）或
   文件 / 目录冲突中止；条目数与**实际写入**字节数有上限（不信头部声明）；不保留 setuid / setgid，只保留「可执行与否」。
   创建 zip 不跟随链接、不读 `.dsh`、写入时排除自身。
7. **复制 / 移动不覆盖**：目标名被占时为 `name (1).ext`；不能把目录放进它自己或子目录（`INTO_ITSELF`）；复制先写到 staging 再 rename。

## 后果

- 正面：每个破坏性操作都可撤销或被拒绝；外部（DSH / 终端）同时修改的文件不会被编辑器悄悄覆盖；恶意压缩包无法写出 staging 之外。
- 代价：回收站占用空间直到 7 天清理；冲突检测要读整个文件算哈希（仅编辑器、≤ 1 MiB）。
- 未做（下一段）：SAF Provider（按 `DocumentsContract` 标志给能力、授权断开的错误）、SFTP Provider（PR-11）、收藏 / 历史、
  「用 DSH 打开此工作区」、Git 项目识别、Diff 预览、Markdown 渲染预览、键的手势。
